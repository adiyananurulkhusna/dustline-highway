Dustline Highway — a desert open-world crime game. Cole "Dusty" Reyes, courier for hire, is caught between the Dust Vipers and the Road Kings in the dusty highway town of Dustline. Explore the town on foot and by car, steal cars, outrun the sheriff's cruisers under a 0–5 star wanted level, and run six story missions with dialogue, chases, timed deliveries and a gang turf war. Top-down 2D, vanilla JS canvas, no libraries, no network requests, synthesized WebAudio sound, HUD with minimap, and localStorage saves. Every name, place, character and sound is original — nothing from Rockstar Games or GTA.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

Controls: WASD / arrows — move & drive · SHIFT — run · E — steal / enter car · F — punch · SPACE / click — shoot · P — pause · M — mute.
